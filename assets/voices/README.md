# Rögzített férfi hangreferencia

A `male-reference.wav` a felhasználó által 2026-11-10-én elfogadott, helyben generált férfi narráció első tíz másodperce. Nem valós ember felvételéből készült. A modellrevízió, az eredeti hang paraméterei és az ellenőrzőösszegek a mellette lévő JSON-ban szerepelnek.

Az alkalmazás ezt egyszer helyben kódolja az OmniVoice hangreferencia-tokenjeivé, és azonos tokeneket használ minden szövegrészhez. Ez erősebb beszélőazonossági feltétel, mint egy szöveges hangutasítás vagy azonos véletlenmag; a tényleges hosszú narráció minőségét ettől függetlenül meghallgatással kell elfogadni.

A referencia személyes, nem kereskedelmi használatra szolgál; az alapjául szolgáló OmniVoice modellsúlyok CC-BY-NC feltételei irányadók. Modell: https://huggingface.co/k2-fsa/OmniVoice
